Building Blocks of a Proof

A theorem is a claim. A proof shows why the claim follows.

✕ A fallacy looks like a valid step but does not justify its conclusion.

Rules of Inference

Modus Ponens Law of Detachment

Symbolic rule

Premise 1p → qPremise 2p
Therefore
∴ q

Assumed premises

If it rains, the road is wet.
It is raining.

What follows? ↓

∴ The road is wet.

The starting condition holds, so its result follows.

Rules of Inference

Modus Tollens

Symbolic rule

Premise 1p → qPremise 2¬q
Therefore
∴ ¬p

Assumed premises

If an angle is right, it measures 90°.
This angle does not measure 90°.

What follows? ↓

∴ This angle is not a right angle.

No required result means no starting condition.

Rules of Inference

Hypothetical Syllogism

Symbolic rule

Premise 1p → qPremise 2q → r
Therefore
∴ p → r

Assumed premises

If you study, you pass.
If you pass, you earn credit.

Link the chain. ↓

∴ If you study, you earn credit.

The shared middle statement connects the two rules.

Rules of Inference

Disjunctive Syllogism

Symbolic rule

Premise 1p ∨ qPremise 2¬p
Therefore
∴ q

Assumed premises

The order is pizza or a burger.
The order is not pizza.

What remains? ↓

∴ The order is a burger.

Remove one option; the other must hold.

Looks Valid. Isn't.

Use the same rain example to spot two wrong turns.

1. Affirming the consequent
p → q + q ✕ ∴ p

Wet road does not prove rain. A sprinkler could have made it wet.

2. Denying the antecedent
p → q + ¬p ✕ ∴ ¬q

No rain does not prove a dry road. The sprinkler may still be on.

3. Begging the question
Claim↻Same claim as “proof”

The conclusion is used to justify itself.

Types of Proof

1Trivial Proof
q is always true

Example: If n is odd, then n² ≥ 0. The result always holds.

2Vacuous Proof
p can never be true

Example: If n² < 0, then n is odd. No integer meets the condition.

3Direct Proof
assume p → steps → q

Example: From 6 | x, write x = 6k and reach 3 | x.

For every integer x, if 6 divides x, then 3 divides x.

Challenges

Simplification1. Given “raining and cold,” what may we infer?

Answer: Either fact separately.

Modus Tollens2. If p → q and ¬q, what follows?

Answer: ¬p, by Modus Tollens.

Fallacy3. Can a proof assume its own conclusion?

Answer: No; that is circular reasoning.

Conclusion

  • Proof path
    Given facts → justified steps → conclusion
  • Valid moves

    ✓ Modus Ponens · Simplification · Modus Tollens
    ✓ Hypothetical · Disjunctive Syllogism

  • Watch for wrong turns

    ✕ Affirming the consequent · Denying the antecedent
