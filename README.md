# Methods of Proof — Group 3

## Open the presentation

Extract the ZIP, then open `index.html` in a current desktop or mobile browser. The slides, fonts, and image asset are local; an internet connection is not needed. Keep `index.html`, `styles.css`, `app.js`, and `assets/` together.

Use the arrows in the footer or the keyboard to change slides. The top-left menu provides the symbol guide, keyboard help, Focus mode, cat jokes, optional voice, and printing. Cat jokes and voice default to off; both can be enabled in the menu. Voice depends on the browser and installed voices. Written cat explanations work without voice.

## Presenter controls

- **Next / previous slide:** Right / Left Arrow, Page Down / Page Up; Space also advances when a control is not focused.
- **First / last slide:** Home / End.
- **Overview:** O or the overview button. Escape closes it.
- **Cat explanation:** E or “Explain This Slide”; S, Escape, or Stop ends it. The full caption appears immediately below the slide.
- **Fullscreen:** F or the fullscreen button. If the browser declines fullscreen, the presentation stays in its window.
- **Keyboard help:** ? or the menu.
- **Slide 2:** “All members” shows the eight names together; “Carousel view” returns to the animated cards.
- **Slide 4:** Select a rule card to jump to its teaching slide. Slides 5–9 reveal example conclusions on demand.
- **Slide 11:** Toggle p and q; the truth table highlights the current case and marks the only false case. It can be hidden or shown.
- **Slide 13:** The first proof step is visible to start the ladder. Next step, Previous step, and Show all control the build.
- **Slide 14:** Try the 8 | x mini-proof on the paper. Undo removes the last stroke and Clear drawing removes all strokes. Drawings remain during resizing and fullscreen changes, but are not saved after closing the page.
- **Slide 15:** Select an answer for each question, then choose Check answers. Retry / reset clears choices and feedback.

Focus mode pauses roaming cat motion and automatic jokes. Roaming is also paused on content-heavy slides. The Focus mode and cat joke choices are saved locally when browser storage is available. Reduced motion is also respected.

## Print a handout

Choose **Print / Save as PDF** from the menu, then select the browser's **Save as PDF** destination. Use landscape orientation and enable background graphics if your browser offers that option. The print layout has one slide per page and shows rule conclusions, proof steps, the truth table, and challenge answers. This produces a PDF handout, not an editable PowerPoint file.

## Scope and checks

The presentation retains 17 slides, all eight original team names, and the original mathematical topics. If the teacher also requires contraposition, contradiction, induction, or proof by cases, confirm that scope before adding them.

The finished deck was checked in headless Chrome at 1366×768, 1920×1080, and six phone sizes from 320×568 to 932×430. All 17 slides were inspected at each size. Navigation, overview, Focus mode, team cards, rule reveals, truth values, proof steps, drawing, quiz, captions, reduced motion, console output, and a 17-page printed PDF were checked. Browser voice availability and the classroom projector should still be checked on the presenting device.
