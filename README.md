# Methods of Proof — Group 3

## Open the presentation

Extract the ZIP, then open `index.html` in a current desktop or mobile browser. The slides, fonts, and image asset are local; an internet connection is not needed. Keep `index.html`, `styles.css`, `app.js`, and `assets/` together.

Use the arrows in the footer or the keyboard to change slides. The top-left menu provides the symbol guide, keyboard help, Focus mode, cat jokes, optional voice, and printing. Voice starts off and depends on the browser and installed voices. Written cat explanations work without voice.

## Presenter controls

- **Next / previous slide:** Right / Left Arrow, Page Down / Page Up; Space also advances when a control is not focused.
- **First / last slide:** Home / End.
- **Overview:** O or the overview button. Escape closes it.
- **Cat explanation:** E or “Explain This Slide”; S, Escape, or Stop ends it. The full caption appears immediately below the slide.
- **Fullscreen:** F or the fullscreen button. If the browser declines fullscreen, the presentation stays in its window.
- **Keyboard help:** ? or the menu.
- **Slide 2:** “All members” shows the eight names together; “Carousel view” returns to the animated cards.
- **Slide 11:** Toggle p and q; “Show truth table” displays all four cases and highlights the current one.
- **Slide 13:** Next step, Previous step, and Show all control the proof build.
- **Slide 14:** Draw on the paper; Undo removes the last stroke and Clear drawing removes all strokes. Drawings remain during resizing and fullscreen changes, but are not saved after closing the page.
- **Slide 15:** Select an answer for each question, then choose Check answers. Retry / reset clears choices and feedback.

Focus mode pauses roaming cat motion and automatic jokes. The Focus mode and cat joke choices are saved locally when browser storage is available. Reduced motion is also respected.

## Print a handout

Choose **Print / Save as PDF** from the menu, then select the browser's **Save as PDF** destination. Use landscape orientation and enable background graphics if your browser offers that option. The print layout has one slide per page and shows rule conclusions, proof steps, the truth table, and challenge answers. This produces a PDF handout, not an editable PowerPoint file.

## Scope and checks

The presentation retains 17 slides and covers the original assigned topics. If the teacher also requires contraposition, contradiction, induction, or proof by cases, confirm that scope before adding them.

Source syntax, local asset paths, slide count, and team names were checked. Visual browser checks, print preview, console inspection, and fresh screenshots could not be completed because the in-app browser connection was unavailable in this session. Test on the classroom projector before presenting, especially the browser's voice and PDF output.
